# ITA 中证 500 指数增强｜分钟行情清洗与验收方案

2026-11-16（北京时间）制定。本方案记录分钟清洗规则及验收范围。清洗后的[分钟最终版](final-factor-data.md)已登记为唯一研究数据集，采用严格版[分钟 Alpha158](minute-alpha158-fit.md) 开展日频因子研究。信号使用 d 日源 14:56 及此前的固定窗口，对应 d+1 收盘执行和 d+2 收盘标签到期。

## 执行顺序

1. **锁定清洗基线与分母。** 复用 `scan_minutes`、`scan_stock_day_corrections`、现有 Polars 分片和修订表，冻结输入、规则、SHA-256 和日历。2016–2025 年、499 股是本地清洗基线，按交易所加证券代码与 ITA 历史中证 500 成分生效区间核对。分别报告本地快照、历史成分与重叠范围，列出整只证券缺席、整日缺席、分钟缺行和字段缺失。全样本按数据问题排查，历史目标名单和绩效不进入清洗分母。
2. **优先核对 14:56 前的特征输入。** 保留源时间戳，以历史市场、板块和交易日的时段规则构造预期网格。休市、午休、隔夜分开。源分钟聚合边界待供应商确认，14:56 只作为源标签。逐字段核验正价格、OHLC 顺序、报价档位、股数、人民币金额、VWAP 合理区间及成交状态。从 14:56 向前统计同一时段 5、10、20、30、60 个预期标签的字段覆盖，另查 60 滞后所需第 61 根。保留固定标签距离，端点资格与整窗资格分别报告。先查影响这些窗口的批量断档和集中入账，再查其他分钟。
3. **并行核对日线收盘端点和必要交易状态。** 在单独的证券日表核对官方或可追溯的不复权收盘、实际成交、历史停复牌、风险警示、上市或退市、除权参考前收和当日限价。按市场日历检查 d+1、d+2 端点是否可用，保留停牌、缺证和超出样本边界原因。核对已生效公司行动和复权因子，记录实际生效与取证时间。未来盘中输入、执行价使用实报未复权价，日线复权信息单独交付。期末 2026 年价格作为独立扩展证据。
4. **单独验收收盘阶段。** 按历史交易机制区分深市、2018-08-20 前后的沪市及特殊时段。分别标记收盘价已核实、原 15:00 有实报但归桶待证、竞价量额有独立证据、推算和缺失。只有经核实的对应交易阶段、价格、股数和金额可进入收盘实报证据。日线差额、末分钟同价、未知排队和全天成交量保留各自证据范围。现有六日 SQL 可作为补证样例，其权限和覆盖缺口独立记录。14:56 前的清洗验收可以先完成。

## 逐键修订规则

| 数据情况 | 当前处理 |
| --- | --- |
| 有合格的原始分钟实报 | 保留实际价格与量额，保留原始证券键、源时钟和来源。 |
| 确认零成交、临停、全天停牌或非交易时段 | 分开标记。确认双零可保留于量额字段，实际成交 OHLC 和 VWAP 留空。非适用时段退出应有分钟分母。 |
| 缺分钟、冲突或疑似集中入账 | 保留预期位置，受影响字段留空并记录原因。已经核实的区间总量额留在原区间。全天汇总、前值和插值均缺少逐分钟成交证据。 |
| 有同键外源实际分钟或交易所逐笔 | 核对时区、归桶、交易阶段、单位和重叠样本后，按证据覆盖的字段生成版本化补丁。保留原值、修订值、来源、时点及证据哈希。 |
| 有官方日行情或区间差额 | 补对应的日级字段或保留对账差额。推算尾盘继续保留独立标记和原有诊断用途。 |

## 验收与交接

- **先做定向缺口盘点。** 在现行读取器上复算按市场、年份、板块、时段、窗口、字段和缺失原因分组的覆盖率，保存分子、分母及逐键缺口。优先复核 2016-01-22 尾盘、2016 年深市集中断档、2024-09-27 沪市异常，再核对正常日、停牌、真实零量、除权和熔断边界。
- **每批修订必须能回读。** 核查证券日与分钟键唯一、输入键守恒、补丁键和字段精确、非目标键保持原值、单位及价格关系成立。修改 14:56 后的记录时复查 14:56 前输入及覆盖完全一致。日线端点和收盘证据分别统计覆盖，无法证实的字段继续带原因留空。
- **清洗阶段交付数据。** 保存版本化修订表、证券日行情与状态表、字段字典、覆盖与缺口清单、规则和 SHA-256 验收记录。ITA 的 P1 数据与基准负责提交，P2 核对时点和输入，P4 核对收盘及交易状态字段。清洗门槛按证据质量和实际覆盖验收，模型样本门槛及执行参数留待研究协议。
