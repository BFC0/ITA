1. **按公式取资格。** `lag=0` 为源 14:56，`lag=60` 为 13:56，`w60` 为 `lag < 60`。固定两端点的 60 分钟收益用 `ret60_endpoints_ok`，取同日 14:56 收盘价除以 13:56 收盘价减一。路径波动等要求全部依赖的价格有效：例如 60 个相邻一分钟收益需要 `w60_close_path_ok` 且 `lag60_close_ok`，不可删掉空分钟后把不相邻标签当成一分钟。OHLC、量额、逐分钟 VWAP 分别使用 `wN_ohlc_ok`、`wN_turnover_ok`、`wN_vwap_path_ok`；仅依赖单字段的公式可直接用相应 `wN_<字段>_ok == N`。窗口总 VWAP 要求完整量额和正的总量，计算 `sum(amount) / sum(vol)`。
2. **保留缺失语义。** `applicable=false` 为临停或熔断时段，最终因子输入为空。适用的正常无成交分钟保留真实零量额，不填价格；未知或冲突字段留空，原因见 `reason` 及原验收的 `gaps_YYYY.parquet`。不插值、不前向填充、不缩短固定窗，也不以日线量额替代分钟量额。聚合前检查资格，避免 `sum` 跳过空值后把部分窗口误当全窗。
3. **按同一样本检验。** 单因子使用自身资格及有效标签。比较增量时，先取各候选的共同 `code,date` 和相同标签，再比较 Rank IC 或模型效果；同时披露各自覆盖。按日、年份查看样本数与缺口集中度，样本不足或截面秩无变化时不报 IC，不能用 0 填代。信号和评分先基于当时可用输入生成，未来端点只用于事后评估，不能用来筛掉当时的可投资样本。日频研究使用本交付的标签。五周课程的周频对照使用配套日线按计划生成周频标签。
