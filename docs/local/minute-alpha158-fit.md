# Alpha158 分钟版输入资格验收

ITA 正式因子库采用严格版分钟 Alpha158 的 158 个表达式，公式版本为本地工作区归档 `artifacts/factor-library/alpha158-minute-validation/20261115T195417+0800/audit.py` 中的 `NAMES` 与 `EXPRS`（相对 QuantResearch 根目录）。信号固定在 d 日源 14:56，窗口为同一下午时段的固定 5、10、20、30、60 个分钟位置；`ROC60` 等最长需要第 61 个位置（13:56）。本次验收覆盖数据与公式，正式因子值及模型验证待开展。 日频研究方案（本地 `data/snapshots/artifacts/factor-library/alpha158-minute-daily-design/20261115T201010+0800/plan.md`）

公式、逐因子资格与验收文件的字段说明见 [Alpha158 分钟版因子说明](minute-alpha158.md)。

从[最终版数据](final-factor-data.md)重算全部 2,430 个交易日的逐字段偏移资格。全期有 996,232 个成交证券日；以下分母为同时满足 `research_eligible` 且有 d+1→d+2 有效标签的 978,561 个证券日。逐日检验表只有分母为正的 2,428 天，期末两个信号日没有冻结样本内标签；输入资格本身在期末仍有计算。

| 因子 | 必需输入 | 可检验样本的输入覆盖 |
| --- | --- | ---: |
| `KMID` / `VWAP0` | 14:56 开盘与收盘 / 14:56 VWAP 与收盘 | 99.67% |
| `ROC60` | 13:56、14:56 收盘价。沿用归档公式 `Ref(close,60)/close` | 98.54% |
| `MA5` / `MA60` | 5 / 60 个连续收盘价 | 98.38% / 81.94% |
| `VMA60` / `VSTD60` | 60 个成交量，普通已知零成交可进入窗口 | 88.44% |
| `CNTP60` / `WVMA60` / `CORD60` | 61 个连续收盘价。另需 60 个成交量位置（`WVMA`）或 61 个成交量位置且滞后量为正（`CORD`） | 81.72% |

至少一项输入合格为 **976,162（99.75%）**，158 项输入全齐为 **799,713（81.72%）**，因子单元输入合格率 **93.23%**。全齐门槛会改变股票构成：日成交额低于 5,000 万元的沪/深样本全齐率为 51.01% / 47.24%，达到 2 亿元的为 87.71% / 90.94%。2016-06-20 的 265 个可检验样本中，`ROC60`、`MA60`、`CORD60` 分别通过 125、96、95 个。两次熔断下午无可用分钟信号。

六个正常或压力日期、共 2,297 个成交证券日，另用本地原生 Qlib 重算 158 项：**43,409** 个因子单元虽有有限值但输入不合格；**2,203** 个输入合格仍得非有限值，集中在 `CORR`（750）、`RSQR`（750）、`CORD`（703）。这六日是诊断样本，不外推全期有限率。另有 549 个可检验证券日通过 `VMA60`、`VSTD60` 的输入检查，但 14:56 成交量为零；原式分母只剩 `1e-12`，可能产生极端的有限值。

接入实验时保留原公式和每列的严格资格：先遮挡不合格输入，再遮挡非有限输出。`VMA/VSTD` 建议做一组「保留原式」对照和一组「当期量为零留空」敏感性测试；如采用变体，单独命名并在开发折定规则。首轮不以 158 项全齐作为全局过滤；研究短窗/端点因子与长窗因子的增量时，用共同证券日和标签，并按日期、市场与流动性报告覆盖。未来标签不能进入信号生成或当时可投资范围的判定。

证据位于 本地 `outputs/alpha158-minute-fit-20261116`：逐公式、逐字段、逐偏移的 本地 `outputs/alpha158-minute-fit-20261116/factor_coverage.csv`，逐键 158 列布尔资格的 `input_eligibility.parquet`，以及 `by_date.csv`、`by_year_market.csv`、`by_turnover_market.csv`、`native_sample_validity.parquet` 和 `manifest.json`。复现：`python -B scripts/audit_minute_alpha158.py alpha158-minute-fit-rerun`（需本地归档公式及 Qlib 0.9.8）。
