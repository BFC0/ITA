# 清洗与验收

本版使用 TRD_Dalyr 日线和 Qlib 交易日历。源行情字段按 CSMAR 字段说明解释，日 K 线映射参考 FMZ。 [CSMAR 字段说明](https://file.csmar.com/group1/M00/AA/99/CuIKV2XAnKiABeLbAB4nDGC5Ano840.pdf) · [FMZ Record](https://www.fmz.com/syntax-guide/struct#record)

| 检查 | 结果 |
| --- | --- |
| 主键与日期 | 按交易所和六位代码构造证券标识，在证券首末观测之间对齐交易日历。重复主键和非交易日记录均为零。 |
| 缺行 | 11,919 个缺行保持价量空值。Qlib 在这些键的收盘价和成交量也为空。公告确认其中 1,052 个属于长期停牌或暂停上市，其余待核实。 |
| 价格与收益 | 保留未复权 OHLC、源后复权收盘价与源收益。发现一条含现金红利再投资的收益与后复权价格变动不一致，排除出研究样本并保留原值。 |
| 涨跌停与历史状态 | 用当日源限价核对价格。研究筛选采用 `Trdsta = 1`，排除已知 ST／*ST、状态码 10、一字报价及限价缺失等记录。 |

`research_eligible` 使用当日收盘后可得字段。固定交易日收益应以市场交易日历计算，并检查持有期端点。此样本的历史退市覆盖、幸存者偏差与成交可行性仍待核实。
