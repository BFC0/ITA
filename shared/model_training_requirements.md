# 模型训练与交付公共要求

适用于量化模型的训练、复测、说明和版本归档。

模型算法、数据范围和数值参数应按任务确定并冻结。

## 一、通用要求

| 要求 | 后续模型如何执行 |
|---|---|
| 使用 Polars 操作数据并优化代码 | Parquet 读取、筛选、关联、日期对齐、清洗及分组统计优先使用 Polars。训练器和优化器可接收 NumPy 矩阵，不要求数值求解本身改用 Polars。避免跨窗口重复读取同一大数据、重复拟合相同预处理。 |
| 滚动窗口训练与测试 | 明确训练、验证、测试窗口及滚动步长，按时间向前推进；每个窗口独立预处理、验证选参及重训，保留逐窗口记录和逐期测试预测。不能只做一次固定分区就称为滚动测试。 |
| 周频预测 | 后续同类股票收益预测默认采用周频；若新任务另有频率则以新任务为准。明确周信号日、信息可得时点、收益起止端点及交易日历。预测频率和重训频率分别说明，不将“每周预测”解释成“必须每周重训”。 |
| 增加夏普率 | 结果必须包含夏普率，说明收益频率、无风险利率、年化因子、标准差口径、样本数、费用和缺失处理；有基准时在相同有效期间比较。 |
| 支持验证窗口平移后复测 | 保留原规则与结果，按指定时间平移验证窗口、重新选参和评估，记录训练、验证及测试边界如何随之变化。对照应使用可比期间；不能覆盖旧结果或只比较不同样本区间的均值。 |
| 写清模型、数据与结果，说明关联报告 | 交付模型说明文档，涵盖目标、方法、数据、训练测试流程、参数、结果、限制及复现。说明链接结果报告、证据和验收；报告或报告导读回链说明，不能只有互不关联的文件。 |
| 模型命名并保存版本 | 确定中文名、稳定模型 ID、版本号及来源运行 ID，冻结代码、规则、训练状态、预测、组合产物和报告；保存输入身份与文件哈希，更新可发现的目录入口。 |
| 在与研究对象匹配的空间中计算 | 在模型设计时确认对象所在的空间、合法取值及运算的含义。需要换坐标时，写明变换、适用范围、还原和验收方法。 |

将窗口平移用作稳定性检验时，在实验计划中预先确定平移量和对照区间。

## 二、正确执行上述要求的配套口径

### 数据与时间边界

- 行情缺失的判定、交易所补录及复权核验按[行情缺失判定与补数规范](market_data_quality.md)执行。

- 写明数据来源、字段、单位、证券标识、时间范围、更新截止日、样本资格与业务唯一键。实际读取文件数、证券数和可交易样本数分开报告。
- 周频特征应由当时可得数据生成或取样；若特征更新较慢，说明真实更新时间。不能把月末因子前填后描述成已经重新计算的周因子。
- 使用市场交易日历定义每周最后交易日，处理节假日和末尾不完整周；不将某只股票更早的观测冒充共同周末。
- 因子筛选、方向、填补、标准化、参数选择均使用相应历史训练或验证数据。训练标签的实际终点必须早于下一分区起点；测试信息不得回流到当期模型。
- 后续滚动窗口可使用已经实现的旧测试期标签，但必须按当时已知信息重训。已观察的历史区间不再称为新的未触碰样本。

### 收益、风险与夏普

- 预测周期、收益实现周期和协方差尺度保持一致，说明使用何种历史收益估计风险。基准需解释其股票池与权重口径。
- 周频夏普可按 `mean(r_week - rf_week) / std(r_week, ddof=1) × √52` 计算；这是所采用的口径，不免除对无风险利率与有效样本的披露。若频率改变，必须相应调整年化口径。
- 毛收益与净费后收益明确区分；没有成交和费用模拟，不报告为实盘绩效。收益缺失不偷偷补零，不根据未来缺失剔除持仓后重新分配权重。
- 策略和基准比较使用共同有效期间，报告总期数、策略完整期数和共同完整期数。缺失造成样本筛选时披露可能偏差。
- 常数收益、样本不足等情况下，无法定义的夏普留空并解释原因，不伪造为零。没有连续完整收益路径时，不强行生成净值或回撤结论。

### 先选空间，再定义运算

在写公式或选算法前，逐项说明研究对象的**原始空间、实际计算空间和最终输出空间**。同一模型中的收益、协方差和组合权重可以各有约束，分别确定在哪个空间计算。

1. **识别对象及其约束。** 写明数据代表什么、单位和尺度、合法取值、坐标顺序及边界。普通实值收益特征可以在欧氏空间中建模。协方差矩阵需对称且半正定，使用正定矩阵流形的方法还要求严格正定。相关矩阵另有单位对角线约束。只做多且全额投资的权重位于单纯形，有单股上限时再加相应约束。把数据存成向量或数组只改变表示方式。
2. **从研究问题出发定义运算。** 对实际用到的距离、平均、差分、投影或优化，写清其经济含义和所采用的度量。确认线性组合是否保留约束，距离是否受单位或坐标选择影响。若欧氏运算或直接约束求解已符合目标，可以直接使用。若选择流形度量，中心可取使样本到中心的平方距离之和最小的 Fréchet 均值。比如将方差 `1` 和 `9` 作为一维协方差，Bures–Wasserstein 距离比较的是标准差 `1` 和 `3`，所以对应中心的方差为 `((1 + 3) / 2)² = 4`，而算术平均方差为 `5`。两种平均分别回答不同的距离问题。
3. **在共同坐标中计算。** 采用切空间方法时，先用预测时点可得的训练数据确定基点，再通过与所选度量配套的 Log 映射，将观测转到同一基点的切空间。在该空间做线性回归、因子提取或时间序列预测时，使用与切空间内积一致的坐标。黎曼 Log 映射由所选几何定义，只有在具体推导支持时才用普通矩阵对数代替。跨窗口比较切向量时，先通过共同基点或适用的平行移动统一切空间，再核对载荷的符号、顺序及子空间旋转。各窗单独估计的因子编号仅在本窗有效。
4. **回到目标空间并检查边界。** 将预测、插值或更新结果用对应逆变换或 Exp 映射还原，再验证原有结构。事前定义局部坐标的适用范围、奇异输入和越界预测的处理。需要收缩、缩步、投影或跳过时，记录规则、触发次数和修正幅度。半正定的实现协方差可以是有效观测，若训练要求严格正定，应另存经正定化的训练输入，保留实现值及其口径。
5. **同时验收几何与实际目标。** 按模型选取能发现错误的检查，例如用手算特例核对距离和均值、在有效域内检验映射往返、检验对称性和特征值。若资产重排理应只改变表示，用一致重排验证风险值或距离不变。在共同样本上与简单方法比较，分别报告结构层误差与最终用途的指标。几何距离改善本身不足以支持切换组合风险模型。

该流程依据文章中“度量决定中心、切空间承载局部线性计算”的方法提炼。Bures–Wasserstein 是协方差研究的一个选择，选用时应说明其与比较零均值高斯分布的关系及尺度口径。[微信解读](https://mp.weixin.qq.com/s/VXt-TxmD_ryqAkm-zDUU-Q) · [Huang、Chen、Chen 原论文第 2 节](https://arxiv.org/html/2607.28385v1#S2)

### 矩阵型风险因子与协方差预测

- 先区分逐证券收益预测的特征和描述联合风险的矩阵型因子。按上节明确协方差的表示和计算空间。比较普通线性法与几何法时，两者使用同一观测口径。矩阵型因子单独登记其风险用途和训练版本。
- 在风险窗口内固定资产维度和顺序，事前确定股票池、收益和协方差尺度、缺失门槛及正定化方法。用共同有效日估计协方差，保留缺失期及原因。正定化的训练矩阵与评估用的实现矩阵分别标识，检查预测矩阵的对称性和特征值。
- 采用 Bures–Wasserstein 黎曼动态因子时，用已完成的历史矩阵估计 Fréchet 中心并做 Log 映射。在切空间内用多个实际日历滞后的自协方差估计载荷，使因子反映跨期持续变化。PCA 则从样本的同期协方差中寻找最大方差方向。在历史窗口内按相邻特征值比率选维，预测因子后用 Exp 映射恢复协方差。记录数值修正、缺失期及收敛失败，避免把缺失期两边接成相邻样本。
- 对照至少包含适用的简单方法（如沿用上期或 EWMA）和项目当前的风险估计。用共同可评分期间同时报告矩阵距离和组合风险误差。隔离协方差预测的影响时使用同一预先确定的权重，比较实际策略时另做与执行频率、收益端点和约束一致的检验。切换默认风险模型前，应有组合层面的样本外证据。
- 协方差研究频率与收益预测频率分别定义。参考[微信解读](https://mp.weixin.qq.com/s/VXt-TxmD_ryqAkm-zDUU-Q) 和 [Huang、Chen、Chen 论文第 2.3 节及第 5 节](https://arxiv.org/html/2607.28385v1)。

### 复测、验证与归档

- 新实验先记录规则与输入身份，再计算；窗口、参数、因子选择或数据改变后另存运行。模型未完成的中间结果不能作为正式交付。
- 进行与修改相称的有效检查，例如未来标签不影响当期预测、标签跨界剔除、周日历与收益端点、权重约束、夏普计算及文件身份。纯文档归档不为凑验收而重跑模型。
- 旧运行、已冻结模型版本与报告不原地改写。更正另存并关联原记录；修改当前说明或入口前备份现有文件，并保护其他人的修改。
- 保存真实代码快照、依赖声明、逐窗口训练状态和输入指纹。哈希证明字节身份，不证明数据质量，也不等于已经拥有独立灾备。

### 公开仓库的敏感信息审查

- 提交前核对拟公开的文件和历史，清除凭据、令牌、个人信息、内部聊天链接、本机路径和未授权材料。仅提交明确可公开的文档、代码、配置模板及合成样例。
- 受限原始数据、课程原件、修订备份、模型产物和运行明细保存在获准访问的位置。通过 `.gitignore` 排除本地目录、环境变量文件和私钥，提交前核对暂存文件清单与差异。
- 推送前检查将随分支或标签发布的所有提交。若敏感内容曾进入待推送历史，先从待发布历史清除并复核。若凭据已经公开，立即撤销或轮换。
- 在干净检出中检查文档链接。将仓库外的内部引用改为仓库内可访问的文件或获准公开的来源。

## 三、每个模型的最小交付清单

1. **模型说明**：模型名/ID/版本、目标、方法、数据、预处理、窗口、参数、结果解释、限制与复现。对涉及受约束对象的计算，写明空间、度量、变换和输出验收条件。
2. **结果报告及关联**：收益、夏普、适当的预测指标和基准；注明频率与样本；与说明文档双向关联到可打开的证据。
3. **训练与测试产物**：逐窗口边界、选参结果、训练状态及必要预处理参数、逐期预测；涉及组合时保存目标权重和逐期收益诊断。
4. **版本与输入身份**：来源运行 ID、代码/依赖/规则快照、输入路径和 SHA256、产物清单；无需为了归档而重复复制全部原始大数据。
5. **验收记录**：实际通过、失败与未检查事项分开写明，文档链接可用；失败或部分完成不能冒充已验收版本。
6. **公共及项目入口**：更新相关 README 或索引，使后续使用者能找到说明、报告及冻结版本；不自动提升因子或模型的实盘状态。
