# 行情缺失判定与补数规范

版本 1.0，2026-11-10（北京时间）。适用于研究使用的行情、因子、收益标签及其衍生数据。

先按「交易所＋证券代码＋交易日」对齐交易日历和证券有效区间，分开统计整行缺席、字段为空、非有限值和真实零值。记录数据源、证券类型、频率、字段和单位，并分别报告各来源、各字段的有效截止日。外连接后的最晚日期只代表合并表的日期范围。

| 看到的情况 | 判定与措施 |
| --- | --- |
| 市场休市，或在证券有效期之外 | 从应有记录的分母排除。证券有效期采用当时可查的上市、退市和代码变更记录。 |
| 有官方停复牌记录或可靠来源标记未交易 | 保存交易状态及证据。参考收盘价可以用于明确规定的估值口径。模拟成交和按成交端点定义的收益标签应按不可交易处理。 |
| 价量全空，且没有历史交易状态 | 标记待核实，查交易所日行情与停复牌公告。仅有零成交、空值或来源查询不到的情况需要保留不确定性。 |
| 明确有交易，主源整行或价量缺失 | 用交易所同一市场、证券、交易日的完整日行情补录。盘中快照、大宗成交和公告可作为交易证据，完整 OHLCV 应来自对应日行情。 |
| 外连接只保留因子侧，或源因子有行无值 | 记录覆盖缺口发生在哪张源表。行情缺失和财务因子缺失分别处理。财务数据需核对公告可得时间、公式和样本范围。 |
| 滚动历史不足、分母无效或常数截面 | 保留不可计算状态并注明原因。常数特征从模型特征集合排除。 |
| 收益端点未交易、无报价或超出样本 | 保留空标签，按原市场交易日历和持有期计算。收益零值应来自真实计算。 |

补数按以下顺序执行。

1. 冻结缺口键和原始输入，优先取交易所日行情、证券参考资料及公司行动公告。保存查询参数、原始响应、日期、哈希和证券类型。先验证日期唯一、报价有效、最高最低关系、成交量和成交额。
2. 用同证券双方都有行情的日期对账。分别核对未复权报价、复权价格、成交量单位、金额单位、VWAP 定义及币种。转换公式应从数据说明与重叠样本同时得到支持。
3. 检查缺口内的除权除息。已公布且生效的公司行动用于重建必要的复权因子，缺口后数据用于验收。使用公告里的适用参考价规则。差异化现金分红应区分实际每股或每份派现和除息参考价使用的虚拟派现。原因或因子仍不明时，保留交易所未复权行情并将调整值标为待核实。
4. 在有来源标记的修订版本落盘。验收实际补入的键、覆盖率、非目标记录及派生字段。使用修订数据时重新计算受影响的滞后和滚动因子、收益标签及样本资格。用修订版本跑模型时另存运行、固定输入身份并记录训练时点。
5. 汇报时区分已补录、已确认未交易、来源覆盖范围之外和仍需核实。将历史补数取得时间与当时市场可观察时间分开记录。
