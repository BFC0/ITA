## 唯一数据源

自 2026-11-11 起，ITA 的真实数据研究只使用 **TRD_Dalyr 2016–2025 清洗版 v1.0.0**。清洗主表是特征、标签、风险估计、组合和回测的唯一源数据。缺行核对表用于审计。派生数据必须记录主表快照 ID 和哈希。公式、业务规则和合成测试样例可继续用于开发。

- 冻结快照 `20261111T102854534571+0800`，覆盖 2016-01-04 至 2025-12-31、499 个沪深证券代码。主键为 `instrument`、`Trddt`。 [字段字典](docs/data/trd-dalyr/FIELDS.md) · [清洗与验收](docs/data/trd-dalyr/CLEANING.md)
- 便携包 `trd-dalyr-2016-2025-clean-v1.tar.gz` 通过获准访问的数据存储取得。解包后的主表位于 `trd-dalyr-2016-2025-clean-v1/data/trd_dalyr_clean.parquet`。开始计算前校验主表 SHA-256 `1b879346499e9b01dafc1dfa870e289f3fd58ab28a46ed1b98b39d2178dd3c9e`。
- 因子公式可复用，因子值须从冻结主表重算。禁止接入独立的 Qlib 行情、L7／课程因子、其他外部数据或用其补值。按市场交易日对齐后计算滞后和收益，按 `research_eligible` 筛选信号日。
- 本表缺少历史中证 500 成分及权重、全收益指数、行业、财报、FF3 和无风险利率。依赖缺失输入的环节记录为阻断；可继续验收仅用本表可计算的部分。证券样本和派生代理须按实际口径命名。后续新增或更换数据源须经项目负责人明确授权并更新本页。
